Drag Techniques & Device Tweaks
J-Drag (Kéo chữ J)

When to use: Close range (0-15m), enemies standing still or moving slowly.

How: Start your swipe slightly to the left or right, then curve upward in a J-shape toward the head. The curved path helps lock onto the head hitbox naturally.

Tip: Use higher general sensitivity (100-100) for fast horizontal movement, lower scope sensitivity for precision.

Straight Drag (Kéo thẳng)

When to use: Medium range (15-30m), enemy in front of you.

How: Swipe straight upward from the fire button. Keep your thumb perpendicular to the screen. Consistent speed is key.

Tip: Practice with Desert Eagle at training ground. Aim for the chest first, then adjust drag distance for head.

C-Drag (Kéo chữ C)

When to use: Long range (30m+), sniper shots, or moving targets.

How: Swipe in a C-shaped arc. Start from one side, curve up and over to the head. This accounts for enemy movement and bullet drop.

Tip: Reduce DPI to 400-600 for long range. Use 4x scope with lower sensitivity (60-70) for stability.

Quick Switch Technique

When to use: When switching between targets rapidly in close combat.

How: After each drag-headshot, quickly switch weapon, then drag again. This resets recoil and maintains accuracy.

Tip: Map weapon switch to an easily accessible button. Practice the rhythm: Drag-Switch-Drag-Switch.

iOS - AssistiveTouch Setup

1. Settings > Accessibility > Touch > AssistiveTouch > ON

2. Customize Top Level Menu: Remove all icons, set to single action

3. Set Tracking Speed to Maximum (Fast)

4. Disable "Hold and Drag" under Pointer Devices if using

Note: AssistiveTouch helps reduce input delay on some iOS devices by bypassing touch sampling rate limitations.

Android - Touch Optimization

1. Enable Developer Options: Tap Build Number 7 times

2. Set Touch Sensitivity: Settings > Display > Touch Sensitivity > ON

3. Reduce animation scale to 0.5x in Developer Options

4. Enable "Show Touches" in Developer Options for practice

5. Set GPU rendering to "Force GPU rendering" for smoother frames

Emulator (Bluestacks/MSI) Settings

1. Set DPI: 400-600 in emulator settings for precise aiming

2. Enable Raw Input in mouse settings

3. Set mouse polling rate to 1000Hz if available

4. Allocate at least 4 CPU cores and 4GB RAM to emulator

5. Enable V-Sync OFF for lowest input lag

Display Response Time Tips

1. Use Game Mode on your device for maximum refresh rate

2. Close all background apps before playing

3. Lower in-game graphics to "Smooth" for stable FPS

4. Enable "High FPS" mode in Free Fire settings

5. For emulator: Enable "High Frame Rate" in emulator display settings
